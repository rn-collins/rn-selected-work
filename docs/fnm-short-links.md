# Fat Nugs print QR codes: short links

Each Fat Nugs article by RN Collins has a permanent short link to its source page, printed under its QR code (Daniel Crawford's request, Nov 20, 2026). The number never changes or gets reused, even if an article is retitled.

- Short link: `rn-selected-work.vercel.app/fn/<n>` (308 redirect to the page)
- Page: `rn-selected-work.vercel.app/sources/fnm/<slug>`
- **Release gate:** both answer 404 until the article's run date, set by RN or Jessica in `data/fnm-sources.json` (`runDate`, a Hawaii date). Nothing opens before its article runs.
- **QR code:** encode the short link exactly, decode-test it, print it at least 2 cm square, with the short link printed under it.
